# 포근동행 프로토타입

초등학교 5학년 수학·영어를 위한 브라우저 실행형 프로토타입입니다. v2 설계의 **중앙 제작·배포 / 기관 검토·매칭·운영**을 반영했습니다.

## 체험 피드백 반영 · 2026-11-05

- **학습 설명과 문제 연결**: 문제를 풀기 전에 짧은 핵심 개념을 확인하고 필요한 선행 차시로 이동할 수 있습니다. 기존 영어 예시의 `lunch`와 수학 예시의 동치분수·통분 설명을 보완했습니다. 답을 기약분수·대분수 등으로 표현해야 하는 문항은 요구 조건을 분명히 안내합니다.
- **교재 범위 확인**: 다른 차시 문항이 포함된 꾸러미는 해당 개념도 학생 설명에 포함하고, 중앙 검토에서 설명·문항 범위와 답의 표현 조건을 확인합니다. 기존 저장 자료·학습 기록은 유지합니다.
- **역할별 체험 안내**: 학생·튜터의 학습 체험과 기관·중앙의 운영 체험을 나눠 안내합니다. 각 단계에서 담당 역할·할 일·완료 결과·다음 행동을 확인하며 진행합니다.
- **자료 탐색과 연결 안내**: 과목·단원·상태로 자료를 좁혀 찾습니다. 꾸러미는 **학생 교재 + 복습 문제 + 튜터 지도안**을 뜻합니다. 중앙 검토·배포, 기관 수신, 예정 클래스 연결의 순서와 담당 역할을 안내합니다.
- **튜터 서류 안내 정정**: 성범죄·아동학대 관련 취업제한 확인의 목적, 본인확인용 회보서와의 차이, 기관 유형에 맞는 동의·조회·회신 확인 절차를 구분합니다. 실제 서류는 제출하지 않고 체험용 파일을 사용합니다.

## 교재 꾸러미 제작·검수 에이전트 · 2026-11-03

**중앙 운영자 → 교재 에이전트** 또는 **자료 제작 → 교재 꾸러미 만들기**에서 시작합니다. 로그인 화면에서는 **가입 없이 예시 화면 체험하기 → 중앙 운영자**를 선택합니다.

- 입력: 초등 5학년, 수학·영어, 단원·참고 차시, 학습목표, 20/40/60분, 기초/기본/도전, 복습 3/5/8문항.
- 출력: 원본의 개념·예제·활동·자기 확인을 보존한 학생 교재, 복습 문항·정답·힌트·해설, 시간 배분과 선수 개념을 포함한 튜터 지도안, 자동 점검 결과.
- **수록 자료 기반 실제 자동 구성입니다. 외부 생성형 AI 호출은 없습니다.** 수학 1~6차시와 11차시(통분)는 수치 변형 문항을 새로 만들고 수식으로 정답을 재계산합니다. 나머지는 같은 차시의 문항 은행을 먼저 사용하며, 8문항 구성에 다른 차시를 포함하면 범위 확장 안내와 해당 차시의 개념 설명을 함께 제공합니다. 지원 범위 밖 자료를 임의로 만들어 내지 않습니다.
- 자동 점검: 필수 내용·예제·활동, 선택지·정답 범위·중복 문항, 시간 합계, 원본·문항 출처, 일부 수학 수치. 목표 변경·편집한 문제/해설·영어 관찰·교육과정 적합성은 사람이 확인할 항목으로 표시합니다.
- 학생 교재·지도안·검토 결과를 한 화면에서 확인하고, 문항과 선택지·정답·해설까지 편집할 수 있습니다. 저장하면 재점검하고 중앙 검토 확인을 초기화합니다. 안전 수정은 공백·빈 선택지·중복 정리와, 원문이 보존된 수치 문항의 정답 위치 복원에 한합니다.
- 생성 → 점검·수정 → 내부 검토 → 중앙 담당자 4개 확인·승인 → 기존 기관 배포·수신·클래스 연결로 이어집니다. 오류가 남은 자료는 검토·승인·배포가 차단되며 자동 점검만으로 승인되지 않습니다. 검토 중 미저장 수정이 있으면 저장 후 초안으로 돌려 재검토하게 합니다.
- 공통 원본·기존 학습 기록을 덮어쓰지 않습니다. 생성본은 별도 ID와 버전으로 저장되고, 배포 뒤 수정은 새 버전으로 진행합니다. 학생별 보충 자동화는 이번 기능에 포함하지 않았습니다.

코드: `dist/material-agent.js`, 테스트: `tests/material-agent.test.cjs`, 브라우저 검증: `node tests/material-agent-browser.cjs`.

## 첫 접속 · 로그인과 회원가입

- 첫 접속 또는 로그아웃 상태에서 로그인 화면을 표시합니다. 내부 화면 주소를 직접 열어도 먼저 로그인 화면을 보여줍니다.
- 학생·보호자 / 튜터 회원가입: 이메일·비밀번호·비밀번호 확인·이름·기관·과목과 매칭 정보를 입력합니다. 튜터 가입에서는 성범죄·아동학대 관련 취업제한 확인 절차를 안내하고 체험용 회신서 파일을 선택적으로 첨부합니다.
- 등록한 계정은 같은 브라우저에서 로그인할 수 있습니다. 이메일 중복, 비밀번호 확인 불일치, 잘못된 비밀번호를 검증합니다. 비밀번호 원문은 저장하지 않고 개별 솔트와 PBKDF2 해시를 저장합니다.
- 같은 탭에서 새로고침하면 로그인 상태를 복원합니다. 로그아웃 후에는 다시 로그인해야 합니다. 가입한 회원에게는 본인 역할·인물만 표시합니다.
- 기관·중앙 운영자 자체 회원가입은 제공하지 않습니다. **가입 없이 예시 화면 체험하기**에서 기존 4개 역할을 검토할 수 있습니다. 체험 모드에서 역할·인물 전환과 예시 데이터 초기화가 가능합니다. 초기화하면 신규 계정도 함께 삭제됩니다.
- 기존 튜터 파일 제출 메뉴는 **내 정보·서류**로 정리했습니다.
- 이 로그인은 브라우저 로컬 계정 흐름을 체험하는 기능입니다. 서버 인증·이메일 인증·비밀번호 재설정·운영용 권한 통제는 연결하지 않았습니다.

## 자동매칭·튜터 가입 및 서류 첨부 · 2026-11-03

- **기관 → 튜터·매칭 → 자동매칭안 만들기**: 미배정 학생의 과목별 후보를 최대 3명 추천하고 승인 대기안으로 저장합니다. 생성만으로 클래스를 만들지 않습니다. 학생·튜터 의사 확인 후 **기관 최종 승인**하면 클래스가 생성됩니다. 반려에는 사유가 필요합니다.
- 필수조건: 소속·자격·서류 확인·참여 동의·과목·학생과 튜터의 가능 시간·정원·일정 및 학습실 충돌. 승인할 때 현재 상태로 다시 확인합니다.
- 초기 추천 배점: 학습 필요/지도 역량 35, 연속 활동 기간(18주 기준) 25, 양측 선호 시간 각 10, 지도 방식 10, 담당 여력 10. 학습 필요와 지도 방식은 선택한 항목의 일치로 계산합니다. 검증된 성공 확률을 의미하지 않습니다.
- 배정 순서: 수업 중단 학생 우선, 대기 시작일이 빠른 학생 우선, 가능 후보가 적은 학생 우선. 자동추천은 학생별 1명 수업안을 생성합니다. **직접 구성·기존 클래스 변경**에서는 1~4명 그룹을 만들 수 있으며 공통 학습 목표·진도 수준을 확인합니다.
- 학생과 튜터의 **매칭 정보**에서 가능/선호 시간, 학습 목표/지도 경험, 지도 방식, 활동 가능 주수, 최대 담당 인원 등을 수정합니다. 기존 가상 인물에는 예시 정보가 추가되며 수업·질문·학습기록은 보존됩니다.
- **회원가입 → 튜터 / 튜터 → 내 정보·서류**: 이름·기관·과목·활동 정보로 신청하고 성범죄·아동학대 관련 취업제한 확인용 회신서를 가정한 **체험용 파일**을 선택적으로 첨부합니다. PDF/JPG/PNG, 10MB 이하를 지원하며 파일 형식·크기와 헤더를 검사합니다. 파일 선택 이름/용량이 표시됩니다.
- 확인 목적은 협력 기관의 유형과 적용 법령에 따른 성범죄·아동학대 관련 취업제한 여부 확인입니다. 필요한 경우 공식 서류명은 **성범죄 경력 및 아동학대관련범죄 전력 조회 회신서**입니다. **본인확인용 범죄·수사경력회보서는 기관 제출용으로 사용하지 않습니다.** [경찰청 범죄경력회보서 발급시스템](https://crims.police.go.kr/main.do), [공식 회신서 서식](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110202&flSeq=156652595&gubun=)을 참고합니다.
- 운영 절차는 **기관의 적용 대상·조회 권한 확인 → 튜터 본인의 동의 → 적법한 조회·회신 확인 → 기관의 참여 자격 확인** 순서로 구분합니다. 프로토타입의 확인 표시가 실제 조회나 동의 처리를 대신하지 않습니다.
- 미제출 → 검토 대기 → 확인 완료 또는 보완 요청. 파일 첨부만으로 자격이 승인되지 않습니다. 기관이 서류의 목적·대상·확인 절차를 검토하고 의견을 남깁니다. 재제출·교체 시 다시 검토 대기로 돌아갑니다.
- 실제 파일은 이 브라우저의 IndexedDB에, 파일명·크기·상태는 기존 예시 데이터에 저장됩니다. 교체한 이전 파일과 초기화 시 첨부 저장소는 삭제됩니다. 동일 브라우저·주소에서 다시 열 수 있습니다.
- **프로토타입 범위**: 가입은 가상 참여자 등록이며 실제 계정 인증이나 서버 업로드가 아닙니다. 역할 전환도 실제 접근 통제가 아닙니다. 실제 개인정보·성범죄·아동학대 관련 회신서를 입력하지 않고 체험용 파일로 진행합니다. 운영 서비스에는 인증·권한·적법한 조회·동의 절차·비공개 서버 저장·보관/삭제 정책을 별도로 연결해야 합니다.

## 실행

- 실행 중인 미리보기: http://127.0.0.1:4320/
- 서버 없이 열기: `포근동행-프로토타입.html`을 브라우저로 엽니다.
- 로컬 서버 재실행: 이 폴더에서 `npm start` 또는 `python3 -m http.server 4320 --bind 127.0.0.1 --directory dist`.
- 외부 라이브러리·네트워크 자산·설치 의존성이 없습니다. 시스템 한글 글꼴과 직접 작성한 SVG를 사용합니다.

상단 역할 전환은 검토를 위한 장치입니다. 학생·튜터는 오른쪽 이름 선택 메뉴에서 체험 인물을 바꿀 수 있습니다. 기관은 오른쪽에서 소속 기관을 선택합니다. 예시 데이터는 현재 브라우저의 localStorage에 저장되며, 서버 주소·포트·브라우저 또는 파일 실행을 바꾸면 저장 공간이 달라질 수 있습니다. 상단 **초기화**에서 예시 상태로 돌아갈 수 있습니다.

## 5학년 1학기 학습자료 · 2026-11-02 추가

상단 또는 왼쪽 **학기 자료** 메뉴에서 수학·영어를 선택합니다. [학기 자료 바로 열기](http://127.0.0.1:4320/#student/semester).

- **18주 보충학습 과정**: 과목별 주 1회 40분, 수학 18차시·영어 18차시. 정규 교과 전체 수업 시수를 대체하는 구성은 아닙니다.
- **총 180문항**: 각 차시에 목표·개념 설명·풀이 예제 또는 대화·활동·도전 과제·자기 확인·튜터 지도안·5문항과 힌트·정답·해설이 있습니다.
- **수학**: 자연수 혼합 계산, 약수와 배수, 대응 관계, 약분과 통분, 분수의 덧셈과 뺄셈, 다각형의 둘레와 넓이.
- **영어**: 초등 5~6학년군 이해·표현 성취기준을 바탕으로 생활 주제를 자체 재구성했습니다. 학교·교과서별 단원 순서에 맞춰 조정합니다. 듣기는 튜터가 예제 대본을 읽어 주며, 말하기·쓰기 활동은 지도안으로 관찰합니다. 선택형 점수를 듣기·말하기 숙달로 해석하지 않습니다.
- **학생**: 자료를 읽고 ‘바로 연습’에서 독립적으로 풀 수 있습니다. 정답·오답 시도는 학습 기록에 저장됩니다. 클래스에 연결된 자료는 기존 복습·튜터 질문 흐름으로도 이어집니다.
- **기관**: 학기 자료의 ‘클래스에 연결’에서 예정 수업에 적용합니다. 모든 예시 기관에 수신된 상태로 수록했습니다.
- **튜터·중앙**: 자료·해설·지도안·교육과정 근거를 열람하고 기존 원본·새 버전 관리 흐름을 사용합니다.
- **기존 데이터 보존**: 저장된 수업·질문·복습·편집 자료를 유지하며 새 자료만 자동 추가합니다. 초기화할 필요가 없습니다.

[전체 차시와 교육과정 근거](학기자료-안내.md)를 함께 확인하세요. 자료의 ‘중앙 배포·검토’ 상태는 프로토타입 시연 데이터이며 실제 교사의 검수·교육부 인증을 뜻하지 않습니다.

| 역할 | 동작 |
|---|---|
| 학생 | 배정된 클래스·차시 자료 보기, 기존 예시 각 3문항 및 학기 자료 차시별 5문항 복습, 오답 힌트·재시도, 문항 질문, 답변 확인·이해 표시·재질문, 내 기록 |
| 튜터 | 담당 수업 준비, 학생 자료·지도안·복습 문제 확인, 수업 시작·출석·마무리·복습 배정, 담당 학생 질문 답변, 자료 오류·개선 의견 |
| 기관 | 참여 상태 보기, 튜터·학생·시간·장소 검토 후 매칭 확정, 변경·재배정, 수업 취소·보강 검토, 중앙 자료 수신·클래스 연결, 지원 조치 |
| 중앙 | 전국·지역별 기관 현황, 기관 상세, 자료 예시 초안·편집·내부 검토, 기관별 배포·수신·사용 현황, 운영 지원 조치 |

기관이 매칭을 직접 검토·확정합니다. 튜터 자격·과목·가능 시간·학생 참여 상태·정원·튜터/학생/학습실 일정 충돌을 확인합니다. 중앙의 매칭 승인 단계는 없습니다.

중앙의 자료는 `초안 → 내부 검토 → 배포 준비 → 배포`를 거칩니다. 기관은 자료 수신 후 예정된 클래스에 연결합니다. 자료 원본은 배포 후 편집할 수 없고 새 버전을 만들어야 합니다. 진행 중이거나 완료한 수업의 자료는 변경하지 않습니다. 이전 질문은 당시 자료 버전을 유지하며 원래 문항을 다시 풀 수 있습니다.

## 추천 체험 순서

상단 **체험 안내**에서 목적에 맞는 경로를 선택하고 화면의 단계 안내를 따라갑니다. 같은 브라우저에서 역할을 바꿔야 학습·운영 기록이 이어집니다.

**학생·튜터 학습 체험**

1. **학생 / 이지우**로 배움방의 자료와 복습 문제를 엽니다. 문제 앞의 개념을 확인하고, 필요한 선행 차시를 살펴봅니다.
2. 복습 문제를 풀고 막힌 부분을 질문으로 보냅니다.
3. **튜터 / 김민서**로 바꿔 질문을 확인하고 답변합니다.
4. 다시 **학생 / 이지우**로 바꿔 답변을 확인하고 이해 여부를 표시하거나 재질문합니다.

**기관·중앙 운영 체험**

1. **기관 → 튜터·매칭**에서 미배정 학생의 매칭안을 검토하고 기관 최종 승인으로 클래스를 만듭니다. 예시로 `박서준`, `이도윤 튜터`, `목요일 17:00`, `학습실 1`을 사용할 수 있습니다.
2. **중앙 운영자 → 교재 에이전트**에서 차시·목표·수업 시간·수준·문항 수를 선택해 꾸러미를 만듭니다. 학생 교재·복습 문제·튜터 지도안을 함께 확인합니다.
3. 설명과 문항의 범위, 답의 표현 조건, 자동 점검 결과를 확인합니다. 필요한 수정 후 내부 검토·중앙 승인을 거쳐 가온센터에 배포합니다.
4. **기관 → 일정·자료 → 배포 자료**에서 해당 자료를 수신하고 예정된 클래스에 연결합니다. 배포·수신·클래스 연결은 각각 다른 단계입니다.
5. **튜터 / 이도윤**으로 새 클래스의 자료를 확인합니다. 수업·복습·질문 흐름까지 이어 보려면 출석 확인 후 복습을 배정하고 **학생 / 박서준**으로 전환합니다.

자료가 많으면 과목·단원·상태 필터로 좁혀 찾습니다. 단계가 막히면 화면에 표시된 선행 작업과 바로가기를 확인합니다. **초기화**는 현재 브라우저의 체험 기록과 신규 계정·첨부를 지우므로, 처음부터 시연하려는 경우에만 사용합니다.

## 프로토타입 범위

- 모든 이름·기관·운영 기록은 가상 예시입니다. 실제 개인정보를 입력하는 용도가 아닙니다.
- 실제 로그인·권한 검증·백엔드 DB·다중 사용자 동기화·알림 발송은 연결하지 않았습니다. 역할 선택은 실제 인증이 아닙니다.
- **기존 예시 초안은 고정 예시를 불러오며, 교재 에이전트는 수록 자료 기반으로 자동 구성합니다.** 외부 생성형 AI 호출은 연결하지 않았습니다.
- 자료 제목·목표·설명·지도안·성취기준 메모는 편집할 수 있습니다. 기존 예시 문항은 고정 세트이며 교재 에이전트의 생성본은 문항·선택지·정답·힌트·해설까지 편집할 수 있습니다.
- 검토 체크리스트는 실제 교과 검수나 공식 교육과정 적합성 인증을 대신하지 않습니다. 성취기준 코드·근거의 자동 검증은 후속 구현 대상입니다.
- 운영 지표는 예시 데이터에서 계산합니다. 보고 시점은 초기 예시 안내이며 실제 전국 기관 실시간 수집은 아닙니다. 복습 시도·이해 자기 확인·지원 조치 완료를 구분합니다.
- 외부 화상수업, 음성 듣기·발음 분석, 실제 기관 등록·계정 인증과 동의 처리, 반복 일정은 이번 범위에 없습니다. 수업 슬롯과 정원은 검토용 예시입니다.

## 파일

- `dist/index.html`, `dist/style.css`, `dist/app.js`: 화면·이벤트·반응형 레이아웃
- `dist/curriculum-math.js`, `dist/curriculum-english.js`: 과목별 학기 콘텐츠
- `dist/material-agent.js`: 수록 자료 기반 교재 구성·수학 문항 생성·자동 점검·안전 수정
- `dist/engine.js`: 예시 데이터·매칭 검토·질문·자료 배포 상태 변경
- `포근동행-프로토타입.html`: 동일한 앱을 포함한 단일 HTML
- `tests/flows.test.cjs`: 핵심 운영·학습 흐름 검증
- `QA.md`: 화면과 기능 확인 결과

검증 명령: `npm run check`, `npm test`. 단일 HTML 갱신: `npm run build`.
