## 브라우저에서 실제로 진행한 연결 시나리오

1. 학생 이지우가 수학 복습에서 오답 선택 → 힌트 피드백 → 해당 문항 질문 작성.
2. 김민서 튜터에게 새 질문 표시 → 설명 작성·답변 → 학생 화면에 답변 도착 → 학생 이해 확인.
3. 기관에서 박서준·이도윤 튜터·목요일 17:00으로 수학 C반 매칭 확정.
4. 중앙에서 수학 v1.3 예시 초안 생성·제목 수정 → 내부 검토. 검토 항목을 빠뜨렸을 때 완료 차단 확인.
5. 4개 항목 확인 후 배포 준비 → 가온센터에 배포 → 기관 자료함에 새 자료 표시 → 수신 확인.
6. 기관이 새 수학 C반에 v1.3 연결 → 박서준 학생에게 새 수업·자료 표시.
7. 이도윤 튜터에게 새 클래스 표시 → 수업 시작 → 수업 메모와 완료·복습 배정 → 박서준에게 복습 버튼 표시.
8. 중앙에서 기관별 자료 수신·클래스 사용·최근 운영 기록 변화 확인.
9. 영어 차시 → 복습 → 첫 문항 정답 선택·피드백 확인.
10. 새로고침 후 앞서 만든 클래스·자료·질문 기록 유지 확인. 체험 인물 선택은 새로고침 시 기본 예시로 복귀.

## 핵심 상태 테스트 7개

1. 기관 매칭 자격·참여·과목·가능 시간·중복 일정 검토와 정상 생성.
2. 중앙 초안 배포 차단 → 내부 검토 → 배포 → 기관 수신 → 클래스 연결.
3. 담당 튜터만 질문 답변 → 답변과 이해 확인 분리 → 재질문.
4. 수업 시작·완료·복습 배정과 오답·정답 시도 기록 분리.
5. 자료 내용 수정 시 검토 상태 초기화·배포 원본과 참조 버전 보존.
6. 운영 지원 완료가 학생 이해·수업 상태를 변경하지 않음.
7. 새 버전 적용 뒤에도 이전 질문에 연결된 문항 복습 가능.

## 확인 범위와 한계

- 실제 계정·권한·전국 기관 데이터·발송·AI 생성은 연결하지 않은 브라우저 저장형 프로토타입입니다.
- 이 검사는 화면·예시 상태 흐름에 대한 검사이며, 실제 서비스의 보안·접근성·교과 검수 인증이 아닙니다.
- 단일 HTML은 구조·스크립트·의존성 검사를 마쳤습니다. 내장 브라우저가 http/https만 허용해 file 주소 직접 실행은 검사하지 못했습니다. 해당 제한을 우회하지 않았습니다.
- 브라우저 검증으로 만든 예시 클래스·자료·질문 기록이 남아 있습니다. 상단 초기화에서 초기 예시로 되돌릴 수 있습니다.
- 데스크톱 반응형 확인에 사용한 임시 viewport는 기본 크기로 복원했습니다.
