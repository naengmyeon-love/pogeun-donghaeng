# 포근동행 · 학생·튜터·기관 UX 설계

2026-11-01 작성. 초등학교 5학년 수학·영어를 대상으로 한 디자인 검토용 제안입니다.

**[디자인 검토 보드 열기](index.html)** — 학생·튜터·기관을 선택하고 UI 시안 / IA / 내비게이션 / 화면흐름도를 비교할 수 있습니다. 인터넷이나 서버 없이 로컬 HTML로도 열립니다. 보드의 전환 버튼만 작동하며, 실제 서비스의 수업·신청·답변 기능을 구현한 프로토타입은 아닙니다.

## 결과물

- UI 시안 3장: 역할별 홈 화면과 주요 상세 화면, 총 6개 화면 예시
- IA 3개: 정보 묶음·콘텐츠·화면 범위
- 내비게이션 구조도 3개: 고정 메뉴·화면 내 이동·복귀
- 화면흐름도 3개: 정상 처리·재질문·보완·대기·지원 흐름
- 세 역할 연결도 1개
- 다이어그램 10개는 각각 PNG와 편집 가능한 SVG로 제공

기존 `와이어프레임.html`과 앞선 10개 스타일 시안은 수정하지 않았습니다. 이번 화면 ID는 이 설계 묶음 안에서 쓰는 새 목록입니다. 이전 와이어프레임의 같은 ID와 이름이 다를 수 있습니다.

## 역할별 UX

학생의 주 메뉴는 **오늘 / 배움방 / 질문**입니다. PC에서는 상단, 모바일에서는 하단에 같은 순서로 배치합니다. 학습 기록은 배움방 안에 둡니다. 학습 질문에는 과목·차시·문항을 자동으로 연결하고 ‘문제 뜻이 어려워요 / 풀이가 헷갈려요 / 내 답을 봐주세요’ 선택지를 제공합니다. 매칭 신청은 기관·보호자 지원 과정으로 두고 학생 홈에는 준비 상태와 다음 안내를 보여주는 안입니다.

튜터의 주 메뉴는 **오늘 / 클래스 / 자료실 / 질문함 / 학습 기록**입니다. 수업마다 승인된 학생 자료·지도안·복습 문제를 함께 사용합니다. 질문 답변 화면에서 당시 자료 버전·문항·학생 시도를 함께 확인합니다. 답변 후에도 재질문과 보충 필요를 추적합니다.

기관의 주 메뉴는 **운영 홈 / 참여 학생 / 튜터·매칭 / 일정 / 지원**입니다. 기관은 소속 참여자와 운영 요청을 관리하며 최종 매칭은 중앙 운영자가 확정하는 제안입니다. 자료 승인은 별도 교과 검토자가 맡습니다. 기관의 조치 완료를 학생의 학습 이해 완료로 처리하지 않습니다.

## 공통 자료 생성·배포 연결

`교육과정·성취기준 확인 → T05 초안 생성·수정 → 검토 요청 → 교과 검토자의 승인 또는 수정 요청 → T04 새 버전 배포 → T03 수업에 선택 → S03·S04·S05 같은 버전 참조`

자료 꾸러미는 학생 자료·튜터 지도안·복습 문제로 구성합니다. 승인 원본은 유지하고 수정 시 새 버전으로 검토합니다. AI 초안은 승인 전 학생에게 노출하지 않습니다. 성취기준과 초5 차시 구성의 적합성, 내용·정답은 교과 검토가 필요한 설계입니다. 이 시안의 수학·영어 내용은 화면 구성을 설명하는 예시입니다.

## 상태와 예외

| 상황 | 제안하는 UX |
|---|---|
| 참여·동의 확인 미완료 | G01에서 필요한 절차·담당 기관·다음 안내 표시 |
| 매칭 대기 | 사유·담당·다음 안내일 표시. 부적합 후보 자동 확정 금지 |
| 질문 전송 실패 | 입력 유지·재시도. 접수 성공 전 대기 완료로 표시하지 않음 |
| 답변 도착 | 이해함 또는 아직 어려움을 직접 선택. 열람만으로 이해 완료 처리하지 않음 |
| 학생 재질문 | 같은 자료·문항·대화 맥락을 유지하고 튜터 답변 대기로 복귀 |
| 튜터 부재 | 기관·운영 지원을 통해 새 담당과 안내 시점을 연결 |
| 자료 수정 요청 | T05 초안으로 복귀 후 다시 검토 요청 |
| 자료 오류 | 검토 요청·영향 범위 확인. 기존 자료를 몰래 덮어쓰지 않음 |
| 기관 지원 미해결 | 재조치·담당 인계. 지원 완료와 학습 완료를 분리 |

## 시각 디자인 기준 제안

- 공통: 밝은 배경, 짙은 본문, 파란 주 행동, 민트·살구색 보조 상태. 색상과 글자를 함께 사용합니다.
- 학생: 본문 18px 전후, 학습 질문 22px 전후, 주 버튼 높이 48–56px를 다음 프로토타입의 시작값으로 제안합니다. 실제 기기·사용자 검증 후 조정합니다.
- 튜터·기관: 본문 16px 전후, 작업 단위별 목록·상태·담당·기한을 함께 표시합니다.
- 상위 이동은 역할마다 일정하게 유지하고, 상세 화면은 뒤로가기와 원래 항목 복귀를 제공합니다.
- 이미지 생성 시안은 색·배치·화면 분위기를 검토하기 위한 것입니다. 텍스트 크기·대비·키보드 이동 등 실제 접근성 준수 여부는 후속 구현에서 확인합니다.

## 범위와 가정

지역 기관의 공간·일정 운영을 포함한 안입니다. 수업 방식(대면·온라인·혼합), 1:1/소그룹 정원, 답변 기한, 기관과 중앙 운영자의 최종 권한은 실제 운영 전에 확정할 항목입니다. 화상회의·공개 커뮤니티·경쟁 순위는 이번 화면에 추가하지 않았습니다. 예시의 인원·이름·날짜는 실제 데이터가 아닙니다.

학생 이미지의 달력은 생성 모델이 넣은 예시이며 실제 일정 기준이 아닙니다. 비교용 분수 도형의 길이·교과 삽화는 최종 학습자료로 사용하기 전에 정확한 공통 단위로 다시 제작합니다.

## 제작과 확인

UI는 내장 `image_gen`으로 생성했고, 튜터의 수식 표현과 기관의 요청 전/후 상태를 추가 수정했습니다. 최종 프롬프트·수정 프롬프트·원본 경로는 로컬 `생성-기록.json`에 있습니다. 다이어그램은 [build_diagrams.py](build_diagrams.py)에서 PNG와 SVG로 동시에 생성합니다.

확인 내용: 다이어그램 10개의 텍스트 캔버스 범위·카드 폭 검사, 대표 IA·내비게이션·흐름도 시각 확인, 최종 UI 3장 검토. 이전 조사 근거는 [초등학생 UI/UX 조사](../../초등학생-UIUX-조사.md), [교육과정 근거](../../교육과정-근거.md)를 이어서 참고합니다.
