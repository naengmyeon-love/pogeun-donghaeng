# 포근동행 발표·체험 가이드

접속 주소: [포근동행 프로토타입 체험](https://pogeun-donghaeng-demo.svbrbmssyf.chatgpt.site)

발표 자료에는 `포근동행-체험-QR.png`를 넣습니다. 흰 여백을 유지하고, 휴대폰으로 인식되는 크기로 배치합니다. 확대·인쇄용으로는 `포근동행-체험-QR.svg`를 사용할 수 있습니다.

## 발표 시작 전

1. 발표 노트북에서 위 주소를 엽니다.
2. 첫 로그인 화면의 **가입 없이 예시 화면 체험하기**를 누릅니다.
3. 처음부터 시연하려면 상단 **초기화**로 예시 상태를 준비합니다. 이어서 **체험 안내**에서 학습 체험 또는 운영 체험을 선택합니다. 초기화하면 현재 브라우저의 체험 기록·신규 계정·첨부 파일이 삭제됩니다.
4. 발표장에서 휴대폰으로 QR을 스캔해 접속을 확인합니다. 연결 문제에 대비해 노트북에는 단일 HTML 파일도 미리 열어 둡니다.

## 학생·튜터 학습 체험

학생의 학습 경험을 먼저 보여 줄 때 선택합니다. 한 브라우저에서 역할을 바꾸며 화면의 현재 단계·할 일·완료 결과·다음 행동을 확인합니다.

1. **학생 / 이지우**: 배움방의 자료와 복습 문제를 엽니다. 문제 앞의 짧은 개념 복습과 선행 차시 연결을 보여 주고 문제를 풉니다.
2. **학생**: 문제에서 막힌 부분을 질문으로 보냅니다.
3. 상단에서 **튜터 / 김민서**로 바꿔 질문을 확인하고 답변합니다.
4. 다시 **학생 / 이지우**로 바꿔 답변을 확인하고 이해 여부를 표시합니다.

발표 멘트 예시: “문제를 풀기 전에 필요한 개념을 확인하고, 혼자 해결하기 어려운 부분은 튜터와 이어서 배웁니다.”

## 기관·중앙 운영 체험

자료 제작과 운영 흐름을 보여 줄 때 선택합니다. 꾸러미는 **학생 교재 + 복습 문제 + 튜터 지도안**입니다.

1. **기관 → 튜터·매칭**: 미배정 학생의 매칭안을 검토하고 기관 최종 승인으로 클래스를 만듭니다. `박서준`, `이도윤 튜터`, `목요일 17:00`, `학습실 1`이 예시입니다.
2. **중앙 운영자 → 교재 에이전트**: 차시·목표·시간·수준·문항 수를 정해 꾸러미를 만듭니다. 학생 설명과 복습 문제의 범위가 맞는지, 답의 표현 조건이 명확한지 확인합니다.
3. **중앙 운영자**: 필요한 수정과 내부 검토·승인을 마친 뒤 가온센터에 배포합니다. 자동 점검만으로 중앙 승인이 완료되지는 않습니다.
4. **기관 → 일정·자료 → 배포 자료**: 수신을 확인하고 예정된 클래스에 연결합니다. 자료가 많으면 과목·단원·상태로 좁혀 찾습니다.
5. **튜터 / 이도윤**: 연결된 자료를 확인합니다. 수업과 복습까지 이어 보려면 출석 확인 후 복습을 배정하고 **학생 / 박서준**으로 바꿉니다.

발표 멘트 예시: “중앙의 제작·검토·배포가 끝나면 기관이 자료를 수신하고 수업에 연결합니다. 각 단계의 담당자와 다음 행동을 화면에서 확인할 수 있습니다.”

## 튜터 서류 안내 시 유의사항

- 화면의 확인 목적은 **성범죄·아동학대 관련 취업제한 여부 확인**입니다. 협력 기관의 유형과 적용 법령에 맞는 조회 대상·권한을 먼저 확인합니다.
- 필요한 경우 공식 서류명은 **성범죄 경력 및 아동학대관련범죄 전력 조회 회신서**입니다. **본인확인용 범죄·수사경력회보서는 기관 제출용으로 사용하지 않습니다.**
- 실제 운영에서는 **기관 적용 대상·권한 확인 → 튜터 본인 동의 → 적법한 조회·회신 확인 → 기관의 참여 자격 확인** 절차가 필요합니다.
- 이 프로토타입은 실제 경찰 조회나 동의 처리를 하지 않습니다. 실제 개인정보·회신서를 넣지 않고 가상 정보와 체험용 파일을 사용합니다. 파일 첨부는 검토 대기이며 기관 확인 완료와 구분됩니다.
- 안내 근거: [경찰청 범죄경력회보서 발급시스템](https://crims.police.go.kr/main.do), [공식 회신서 서식](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110202&flSeq=156652595&gubun=).

## 참석자에게 안내할 내용

“QR로 접속한 뒤 **가입 없이 예시 화면 체험하기**를 눌러 주세요. **체험 안내**에서 학생·튜터 학습 체험 또는 기관·중앙 운영 체험을 고르면 단계별로 따라갈 수 있습니다. 상단의 역할과 이름 선택 메뉴를 안내에 맞춰 바꾸어 주세요.”

- 체험 상태는 각자의 브라우저에 저장됩니다. 다른 참석자의 체험에는 영향을 주지 않습니다.
- 여러 기기 사이에서 질문·답변·자료가 공유되지는 않습니다. 연결된 흐름은 같은 브라우저에서 역할을 바꾸며 확인합니다.
- 역할 전환과 예시 인물 선택은 시연용입니다. 가상 예시를 사용하고 실제 개인정보는 입력하지 않습니다.
