## 초기 와이어프레임

초등학교 5학년 **영어·수학**을 위한 학생–대학생 튜터 매칭 및 학습지원 서비스의 화면 구조 검토본입니다. 프로토타입 개발 전에 **자료 생성·검토 → 공통 자료로 수업 → 온라인 복습 → 튜터 질문 → 다음 수업 보충**의 연결을 확인합니다.

## 화면 열기

[와이어프레임.html](와이어프레임.html)을 브라우저에서 엽니다. HTML 안에 스타일·스크립트가 모두 들어 있으므로 별도 설치나 빌드 없이 볼 수 있습니다.

- 첫 화면은 학생의 **오늘의 학습**입니다.
- 왼쪽 화면 목록에서 13개 화면을 이동합니다. 모바일에서는 상단의 화면 선택 메뉴를 사용합니다.
- 상단 **전체 흐름 보기**에서 서비스 구조와 역할을 한눈에 볼 수 있습니다.
- 수학·영어 버튼으로 과목 예시를 바꿉니다. 튜터 화면의 과목 전환은 서로 다른 담당 튜터 화면을 비교하기 위한 장치입니다.
- **검토용 상태 예시** 메뉴로 질문 작성·답변 대기·이해 확인, 복습 피드백, 자료 생성·검토·배포 전후를 비교합니다.
- 화면의 검은 번호와 오른쪽 설명을 함께 봅니다. 작은 화면에서는 설명이 본문 아래에 표시됩니다.

버튼은 화면 이동 또는 동작의 의미를 설명하는 안내를 보여줍니다. 실제 학생 정보 입력, 신청·매칭, AI 생성, 답안 채점, 메시지 전송, 데이터 저장은 하지 않습니다. 색상·브랜드·일러스트를 확정하기 전의 회색조 와이어프레임이며, 실제 배포용 교육콘텐츠도 아닙니다.

## 13개 화면

| 구분 | 화면 |
| --- | --- |
| 전체 구조 | O01 서비스 전체 흐름 |
| 학생 | S01 오늘의 학습 · S02 튜터 매칭 · S03 내 클래스룸 · S04 온라인 복습 · S05 질문과 답변 |
| 대학생 튜터 | T01 대시보드 · T02 수업 준비·진행 · T03 질문 답변 |
| 공통 자료 | C01 공통 자료실 · C02 학습자료 초안 만들기 |
| 검토·운영 | A01 자료 검토·배포 · A02 매칭 관리 |

## 먼저 볼 동선

1. **학생:** 오늘의 학습 → 복습 이어 하기 → 여기서 막혔어요 → 질문 작성. 질문 상태 메뉴에서 답변 도착·이해함·재질문을 비교합니다.
2. **튜터:** 대시보드 → 수업 준비 → 공통 지도안·학생별 보충 → 복습 배정의 위치를 확인합니다. 질문함에서 원래 문항과 학생 질문을 함께 봅니다.
3. **자료:** 공통 자료실 → 새 자료 초안 만들기 → 성취기준·수업 목표 → AI 초안 상태 → 검토자 화면 → 수정 요청 또는 승인 상태를 비교합니다.
4. **매칭:** 학생의 신청·대기·확정 상태와 운영자의 조건 확인·배정 화면을 비교합니다.

수업·복습·질문은 같은 **자료 ID·버전·문항 ID**를 참조하는 설계입니다. 공통 원본을 유지하면서 튜터가 학생별 보충 설명을 더합니다. AI 초안은 사람이 검토·승인한 뒤에만 공통 자료로 배포하는 안입니다.

## 로컬 서버로 확인할 때

단일 HTML을 직접 열기 어려운 환경에서는 프로젝트 루트에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 4318 --bind 127.0.0.1 --directory 포근동행
```

브라우저에서 [와이어프레임 로컬 주소](http://127.0.0.1:4318/와이어프레임.html)를 엽니다. 확인을 마치면 터미널에서 `Ctrl+C`로 종료합니다.
